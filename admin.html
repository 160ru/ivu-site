Редактор товаров

Заполните поля и нажмите «Опубликовать» — товар уйдёт в репозиторий, через минуту появится на витрине. Страница не индексируется и не связана с меню.

Доступ

Токен создаётся один раз: GitHub → Settings → Developer settings → Fine-grained tokens → доступ только к репозиторию ivu-site, права «Contents: Read and write». Больше ничего не давайте.
