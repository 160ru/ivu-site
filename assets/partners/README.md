# Логотипы партнёров: откуда взяты

Файлы в этой папке — знаки вендоров, с которыми работает компания.
Ниже источник каждого; при обновлении бренда вендора файл нужно заменить.

| Файл | Вендор | Источник | Проверка |
|---|---|---|---|
| `1c-franchisee.gif` | 1С | `1c.ru/logos/franlogo.gif` — официальный знак для франчайзи | совпадает побайтово |
| `1c.svg` | 1С | знак «1С» без подписи | — |
| `rudesktop.svg` | RuDesktop | `rudesktop.ru/img/logo.svg` | совпадает побайтово |
| `3cx.svg` | 3CX | Wikimedia Commons, `3CX_logo.svg` | совпадает побайтово |
| `rucenter.svg` | RU-CENTER | Wikimedia Commons, `RU-CENTER_logo.svg` | совпадает побайтово |
| `drweb.svg` | Dr.Web | официальный логотип с надписью «Anti-virus» | происхождение не подтверждено |
| `devline.svg` | Devline («Линия») | знак «Линия» | официального файла в открытом доступе нет |

**Что делать при обновлении:** заменить файл, сохранив имя, — вёрстка подхватит
автоматически (в плитке партнёров высота ограничена 40 px, ширина по пропорциям).
