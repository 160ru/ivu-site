# Витрины: новая техника и барахолка

Две страницы с товарами:

- **`new.html`** — новая техника;
- **`used.html`** — барахолка, б/у.

Обе читают один файл `data/products.json`, фотографии лежат в `assets/products/`.

---

## Как добавить товар — через форму

1. Открыть **<https://ivu.ru/admin.html>** — страница не в меню и не индексируется.
2. Один раз вставить токен GitHub (см. ниже). Он сохранится в браузере.
3. Заполнить поля: витрина, название, цена, состояние, описание.
4. Выбрать фотографию — она автоматически сжимается до 1200 px по длинной стороне.
5. Нажать **«Опубликовать»**.

Через минуту товар появится на сайте: форма коммитит изменения в репозиторий,
а автовыкладка раскладывает их на хостинге.

Форма работает только в том браузере, где введён токен. Ничего не отправляется
на сторонние сервисы: запросы идут напрямую в GitHub.

---

## Токен GitHub — один раз

1. Открыть <https://github.com/settings/tokens?type=beta>
2. **Generate new token** → имя `ivu-admin`.
3. **Repository access** → *Only select repositories* → `160ru/ivu-site`.
4. **Permissions** → *Repository permissions* → **Contents: Read and write**.
   Больше ничего включать не нужно.
5. Срок действия — на ваш выбор, например год.
6. Скопировать токен и вставить в поле на странице `admin.html`.

Если токен попадёт к постороннему, он сможет менять только файлы этого
репозитория. При подозрении — удалить токен в GitHub, создать новый.

## Формат записи в `data/products.json`

```json
{
  "updated": "2026-11-28",
  "new": [
    {
      "title": "Ноутбук Lenovo ThinkPad E14, 16 ГБ",
      "price": 45900,
      "condition": "Новое",
      "date": "ноябрь 2026",
      "desc": "Гарантия 1 год, чек и документы для юрлица.",
      "image": "noutbuk-lenovo-123456.jpg",
      "avito": "https://www.avito.ru/ivanovo/noutbuk_lenovo_123456",
      "sold": false
    }
  ],
  "used": []
}
```

Поля:

| Поле | Обязательное | Что значит |
|---|---|---|
| `title` | да | название на карточке |
| `price` | нет | число в рублях; пусто или 0 — «цена по запросу» |
| `condition` | нет | подпись-метка: «Новое», «Б/У», «После проверки» |
| `date` | нет | произвольная подпись, например «ноябрь 2026» |
| `desc` | нет | 1–3 предложения, что важно покупателю |
| `image` | нет | имя файла в `assets/products/` |
| `avito` | нет | ссылка на объявление Авито — под кнопками появится «Смотреть на Авито →» |
| `sold` | нет | `true` — карточка затемняется плашкой «продано» |

Товары показываются в порядке добавления: новые записи форма ставит в начало.

## Фотографии

- форма сжимает снимок до 1200 px и сохраняет в JPEG — обычно 80–150 КБ;
- имя файла формируется автоматически из названия;
- формат кадра — 4:3, карточка обрезает по центру;
- одна фотография на товар. Несколько потребуют галереи — скажите, добавим.

## Ссылка на Авито

Для барахолки удобно дублировать лот на Авито и давать ссылку с сайта:

- в форме-редакторе есть поле **«Ссылка на объявление Авито»**;
- в карточке под кнопками появляется строка **«Смотреть на Авито →»**;
- если поле пустое, строка не показывается.

Так человек, который ищет на Авито, находит вас, а тот, кто на сайте, видит
объявление с фото и отзывами площадки. Дублирование не вредит поиску: это
разные страницы, и на каждой свой канонический адрес — для сайта это `used.html`.

## Как товар «продаётся»

Кнопка **«Заказать»** открывает чат в карточке Яндекс.Карт — там вы отвечаете
и договариваетесь. Рядом кнопка «Позвонить» на +7 4932 353070.

Когда товар продан — в `admin.html` его нужно только пометить. Пока проще
сказать мне или поправить `sold` в файле вручную: форма добавляет, но не
редактирует существующие записи. Если таких правок станет много, сделаю
в редакторе список и кнопку «продано».

## Что стоит учесть

- Цены на витрине видны всем. Если не хотите публиковать, оставляйте поле
  пустым — будет «цена по запросу».
- Барахолка — витрина б/у техники. По закону о защите прав потребителей
  б/у товар юрлицу можно продавать по договору; физическому лицу — с
  оговорёнными недостатками. Пусть формулировки в описании не обещают
  «новое», если это не так.
- Для поиска страницы уже в `sitemap.xml`, у каждой свой `title`
  и `description`.
